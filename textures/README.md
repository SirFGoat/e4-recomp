# Textures

Optional. `dump/` receives textures saved by `e4recomp/dump_textures.bat`; put your own
high-resolution replacements in `replace/` (any subfolder; the file name must keep the
`_<hash>.png` ending). `replace/@glow/` is written by `e4recomp/glow/make_glow.bat`.
See the main README. Nothing in this folder is ever committed.
