# Game files go here

Extract your own copy of the E4: Every Extend Extra Extreme Xbox Live Arcade package
(title ID 58410872) into this folder:

    python tools/stfs_extract.py "<path to the package file>" game

You should end up with `game/default.xex`, `game/Media/...` and a few PNG/XML files.
Nothing in this folder is ever committed (see .gitignore).
